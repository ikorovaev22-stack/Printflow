# ROADMAP

## Сделано в версии шаблона

- [x] Свой сервер в РФ: Docker + Caddy с прокси Supabase (работает без VPN), инструкция для Selectel
- [x] Файлы в заказе: макеты от клиента, пробники от типографии
- [x] Push- и email-уведомления о статусах, файлах и сообщениях
- [x] История этапов с датами, часовой пояс компании
- [x] Тёмная тема
- [x] Восстановление пароля и подтверждение email через свой домен
- [x] Безопасность: пароль от 8 символов, лимиты попыток и сообщений, лимиты полей, CSP, только растровые логотипы
- [x] Скрипт создания типографии, демо-режим, e2e-тесты

## Перед запуском с реальными клиентами

- [ ] Не включать `DEMO_MODE` и не создавать демо-аккаунты в рабочей базе
- [ ] Своя почта (SMTP) в Supabase и шаблоны писем из `supabase/templates/`
- [ ] Резервные копии базы (тариф Supabase с бэкапами или регулярная выгрузка `pg_dump`)
- [ ] 152-ФЗ: персональные данные граждан РФ хранить на серверах в России — self-hosted Supabase или Managed PostgreSQL в РФ
- [ ] Поднять лимиты Supabase Auth, если клиентов много (все запросы идут с адреса сервера)
