# ROADMAP

## 1. Перенос на российский хостинг (приоритет)

**Почему:** Vercel частично заблокирован в РФ — сайт открывается только через VPN. Браузер также ходит напрямую
в `*.supabase.co` (чат, realtime, загрузка логотипа). Прокси через Cloudflare не подходит: российские провайдеры
режут его трафик до 16 КБ. Свой `.ru`-домен на Vercel не помогает (по-прежнему серверы Vercel).

**Решение:** Selectel VDS + домен `.ru`, браузер обращается только к нашему домену.

- [ ] Заказать Selectel **VDS 2-2-40** (2 vCPU / 2 ГБ / 40 ГБ, Ubuntu 24.04) — 400 ₽/мес (3 ТБ трафика и IP включены; НДС уточнить при оплате)
- [ ] Купить домен `.ru` (~200–900 ₽/год), A-запись на IP сервера
- [ ] Запуск Next.js на сервере: `output: "standalone"` + Docker (или systemd), nginx как reverse proxy, HTTPS через Let's Encrypt
- [ ] Прокси Supabase через свой поддомен (`sb.<домен>` → `<project>.supabase.co`) с поддержкой WebSocket
      (realtime), REST, Auth и Storage; `NEXT_PUBLIC_SUPABASE_URL` → адрес прокси
- [ ] Перенести переменные окружения (только anon key и URL; service role — не на сервер приложения)
- [ ] Проверить без VPN: мобильный интернет (МТС, Билайн, МегаФон, Теле2) и домашний
- [ ] Обновить ссылки в README, manifest, лендинге; Vercel оставить как запасной вариант или отключить
- [ ] Позже: перенести базу в РФ (self-hosted Supabase на Selectel или Managed PostgreSQL) — требование 152-ФЗ
      о локализации персональных данных граждан РФ

Итого по деньгам: ~400 ₽/мес за сервер + домен ≈ 450–480 ₽/мес.
