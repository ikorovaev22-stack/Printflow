# DESIGN.md

Правила визуального стиля приложения. UI построен на shadcn/ui + Tailwind v4; токены живут в `src/app/globals.css`.

## Характер

- Светлый спокойный фон, белые карточки без теней и обводок: глубину дают фон и скругления.
- Одно главное действие на экран — тёмная пилюля. Лаймовый — единственный яркий акцент, он означает «готово».
- Важный объект показывается тёмной «герой»-карточкой (как фото-карточка в референсах): крупный белый текст, полупрозрачные пилюли, растровая текстура (отсылка к полиграфии).
- Фильтры — пилюли: активная тёмная, остальные белые.
- Нижняя навигация — плавающая белая пилюля, активный пункт — тёмная пилюля с подписью.

## Цвета (токены)

| Токен | Значение | Использование |
|---|---|---|
| `background` | `#F3F3F5` | фон экранов |
| `card` | `#FFFFFF` | карточки, поля, плавающие панели |
| `muted` / `secondary` | `#EBEBEE` | неактивные чипы, плитки иконок, поля на белом |
| `foreground` / `primary` | `#1C1C1E` | текст, основные кнопки, тёмные герой-карточки |
| `muted-foreground` | `#6E6E73` | подписи, вторичный текст (≥4.5:1 на белом) |
| `hero` | `#1C1C1E` | тёмные герой-карточки (в тёмной теме `#2A2A2E`) |
| `lime` | `#D7F25B` | статус «Готов», плитка «Готовы к выдаче», CTA на тёмном |
| `brand` | цвет компании | текущий этап, логотип-заглушка, акценты превью |
| `destructive` | `#DC2626` | выход, ошибки, счётчик непрочитанных |
| `border` / `input` | `#E6E6EA` / `#E3E3E8` | разделители в плотных списках, рамки полей |

- Фирменный цвет компании — **акцент**, а не цвет кнопок: основные действия всегда тёмные.
- Статусы заказа: подпись + цветная точка (никогда только цвет). «Готов» — лаймовая плашка.
- Сырые hex в компонентах не используем — только токены (`bg-card`, `text-muted-foreground`, `bg-lime`, `bg-brand`).

## Типографика

- Шрифт: **Onest** (переменный, 100–900, кириллица), подключён через `next/font`.
- Заголовок экрана: 32px, 700, межстрочный 1.1, `tracking-tight`. Над ним — приглушённая строка 18px («Добрый вечер, Анна»).
- Заголовок секции: 18px, 600.
- Основной текст: 15–16px, 400; подписи: 12–14px, `muted-foreground`. Минимум — 12px (кроме счётчиков 10px).

## Радиусы, тени, отступы

- `rounded-card` = 24px — карточки и секции; `rounded-tile` = 16px — поля ввода, плитки иконок.
- Кнопки, чипы, поиск, навигация, значки — `rounded-full`.
- `shadow-float` — только для плавающих панелей (таб-бар, панель действия, поле чата).
- Поля экрана 20px; ритм секций 32px; внутри секции 12–16px; зазор карточек 8–12px.

## Компоненты

- `Button`: варианты `default` (тёмная), `surface` (белая на сером), `glass` (на тёмном), `lime`, `outline`; размеры `lg` = 48px, `icon-lg` = 48px.
- `Screen` + `SectionTitle` — каркас мобильного экрана; `FloatingBar` — плавающая панель снизу.
- `StatusBadge` (тона `default`, `glass`, `ink`), `OrderProgress` (сегменты), `OrderTimeline`.
- `Empty` — все пустые состояния. `Halftone` — декоративная текстура только на тёмных поверхностях.
- Админка: белое боковое меню, активный пункт — тёмная пилюля; таблицы в `rounded-card` без рамки; KPI-плитки сверху.

## Тёмная тема

- По умолчанию — как в системе; клиент переключает в профиле, сотрудник — кнопкой внизу меню (next-themes, класс `.dark`).
- Тёмные токены: фон `#0F0F10`, карточки `#1C1C1E`, `muted` `#2C2C2E`, текст `#F5F5F7`, приглушённый `#A1A1A6`. Основные кнопки становятся светлыми.
- Тёмные «герой»-карточки используют токен `hero` (`bg-hero text-hero-foreground`), а не `primary`: в тёмной теме `primary` светлый.
- Фирменный цвет задаёт `brandStyle()` вместе с классом `brand-scope`; почти чёрный бренд в тёмной теме автоматически становится светлым.

## Технические правила

- Новые компоненты shadcn импортируют `cn` из `@/lib/utils` (CLI ставит `from "cn"` — замените): там зарегистрированы токены `rounded-tile`, `rounded-card`, `shadow-float`.
- Даты — через `src/lib/format.ts` с часовым поясом компании (`company.timezone`, в клиентских компонентах — `useTimeZone()`).

## Доступность и поведение

- Цели касания ≥44px; иконки-кнопки с `aria-label`; текущий раздел — `aria-current`.
- Нажатие — `scale-97/98`, отключается при `prefers-reduced-motion`.
- Контент не прячется под плавающими панелями (нижний отступ + safe-area).

## Чего не делаем

- Тени на обычных карточках, градиенты на фоне экранов.
- Больше одного яркого акцента на экране.
- Цвет как единственный носитель смысла.
